# Social Media Platform

## 📌 Project Description

A full-stack social media platform developed using Node.js, Express.js, MySQL, EJS, HTML, CSS, and JavaScript. The application allows users to register, log in, manage profiles, and interact through a secure web interface.

## 🚀 Features

- User Registration
- Secure Login Authentication
- User Profile Management
- Session Management
- Responsive User Interface
- MySQL Database Integration

## 🛠️ Technologies Used

- Node.js
- Express.js
- MySQL
- HTML
- CSS
- JavaScript
- EJS

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/PatarlaYamini/Social-Media-Platform.git
```

2. Install dependencies

```bash
npm install
```

3. Start the application

```bash
node app.js
```

4. Open in your browser

```
http://localhost:3000
```
